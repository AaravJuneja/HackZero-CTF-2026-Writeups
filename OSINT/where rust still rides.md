# Where Rust Still Rides

## Description

A track remains -- weathered, wooden, and overtaken by time -- cutting through what was once a place built for motion and thrill. The structure still stands, long after the crowds disappeared and the gates were closed. Its purpose is clear, but its identity is not immediately given. This image captures more than decay -- it captures something that still exists, waiting to be recognized.

Your task:
Identify the location of this abandoned site
Identify the name of the ride shown
Identify the original photographer of this image

Flag format: hackzero{location_name_coaster_name_photographer_name}

## Writeup

Google lens gave me a direct hit on the image: `https://rcdb.com/693.htm#p=125876` with the general link being `https://rcdb.com/693.htm`

From this link, we can see the following details:

- At bottom left of this found image we can see the name of the photographer as: `Owen Varga`
- Location of the image is `Chippewa Lake Park` (Chippewa Lake, Ohio, United States)
- Roller coaster name is: `Little Dipper`

## Flag

Putting it all together, the flag format would be:
`hackzero{chippewa_lake_park_little_dipper_owen_varga}`
